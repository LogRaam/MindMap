# MindMap

Application de cartes mentales (mind mapping) dans le navigateur, inspirée de Mindjet MindManager.
Un seul fichier `index.html`, sans installation ni dépendance : ouvrez-le dans Chrome ou Edge,
ou utilisez-la en ligne : **https://lograam.github.io/MindMap/**

## Fonctionnalités

- Carte **vers la droite** ou **gauche + droite** (bascule dans la barre d'outils)
- Créer, éditer, supprimer, replier / déplier des sujets ; sélection multiple
- Déplacer des sujets ou des groupes par glisser-déposer (Ctrl en déposant = copier)
- Zoom (Ctrl+molette) et déplacement de la vue (glisser le fond)
- **Couleurs** et **icônes** par sujet (priorités, états, pastilles, symboles) — clic droit ou 🎨 Format
- **Notes** attachées aux sujets (F4), avec mise en forme : gras, italique, souligné, barré, titres, listes, citations, couleurs, surlignage, liens
- Annuler / rétablir
- Enregistrer / ouvrir en `.json` ; import des fichiers **MindManager `.mmap`** (sujets et notes mises en forme) et de plans `.txt`
- Copier / coller de branches ou de la carte entière, en plan indenté compatible avec Word, MindManager, courriels
- Export **PNG** (fichier ou presse-papiers) et **Markdown Mermaid** (`mindmap` ou `flowchart LR`)
- Sauvegarde automatique dans le navigateur

## Raccourcis principaux

| Touche | Action |
| --- | --- |
| Entrée / Maj+Entrée | Nouveau sujet après / avant |
| Insert ou Tab | Nouveau sous-sujet |
| F2, double-clic ou taper du texte | Éditer le sujet |
| Suppr | Supprimer la sélection |
| Espace | Replier / déplier |
| Flèches | Naviguer |
| Ctrl+↑ / Ctrl+↓ | Réordonner parmi les frères |
| Ctrl+C / X / V | Copier / couper / coller |
| Ctrl+Z / Ctrl+Y | Annuler / rétablir |
| Ctrl+S / Ctrl+O | Enregistrer / ouvrir |
| Ctrl+0 | Ajuster à la fenêtre |
| F4 | Panneau des notes |
| F1 | Aide complète |
